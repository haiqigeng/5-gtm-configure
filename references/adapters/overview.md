# Adapter selection

Prefer the connected GTM MCP, then the authorized API, complete export/import, or signed-in UI for unsupported fields. Inspect actual capabilities before choosing a route. All transports use the same execution engine.

Read [MCP profiles](mcp-profile.md) and your host guide: [Codex](codex.md) or [Claude/Gemini SDK](mcp-sdk.md). For a custom API/import/UI transport use [the adapter protocol](custom.md). Read [discovery](discovery.md) only when fresh preparation inventory is needed, and [quotas](quotas.md) for large runs or typed quota failures.
